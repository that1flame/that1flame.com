# that1flame.com
My personal website featuring my projects and more.

## Why is this public?
I know people struggle learning how to code. It took me *forever* to finally get the hang of HTML/CSS.
I saw sites I thought were cool, looked at the source code to see how they functioned, and understood... nothing.

Because of this, I figured I'd share some code *I* make with the world, in case anyone wants to see how it was made.
Inside (most of) my code are comments, either directed to myself to remember later or for anyone curious as to what something does.

I hope this helps someone learn, and thank you for checking this repository out <3
